# 下一阶段三方向实验计划

计划制定于 2026-07-30。当前状态为**方案已确认，尚未开始数据整理和训练**。

## 1. 依据和判断

- Qwen3.6 微调后明显超过自身 Base，但最佳 E5-780 在阶段 Test N=241 上为 Recall 69.70%、FPR 22.86%、Accuracy 75.10%、F1 60.53%，没有超过 Qwen3.5 的历史最佳结果。
- 各正式 LoRA 的严格 JSON 合法率已达到 100%，当前瓶颈主要是视觉判别和跨分布泛化，而非输出格式。
- 现有 Dev 只有 58 个 BAD，阶段 Test 只有 66 个 BAD，统计稳定性不足；继续细调训练参数的价值低于增加独立数据和建立新盲测集。
- 后续优先推进三个方向：新增独立数据、训练专用视觉分类器、改造 Qwen3.5 的视觉输入和监督目标。暂不优先更换大型 VLM 基模，也不进行宽泛扫参。

所有模型均以图片级 GOOD/BAD 为核心任务。扩展 Dev 用于模型和阈值选择；当前阶段 Test N=241 不再参与选择；新的盲测 Test 在候选模型、阈值和 Prompt 冻结后只运行一次。

## 2. 方向一：新增数据与评测集

第一阶段新增 12,000 张独立图片，不包含现有约 8,026 张训练原图：

| 用途 | GOOD | BAD | 合计 |
|---|---:|---:|---:|
| Train | 4,000 | 4,000 | 8,000 |
| 扩展 Dev | 1,000 | 1,000 | 2,000 |
| 新盲测 Test | 1,400 | 600 | 2,000 |
| **总计** | **6,400** | **5,600** | **12,000** |

重点要求：

- 新数据只有 GOOD/BAD 标签即可，不要求补充错误原因。
- 按来源、生成任务或主体系列分组切分；同源图、裁剪图和近重复图不能跨 Train/Dev/Test。
- 正式划分前抽检 GOOD/BAD 各 200 张；若任一类别标签反转率超过 5%，先统一标注标准并重新抽检。
- 新增 Train 构造 D2K、D4K、D8K 三个严格嵌套子集，每档 GOOD/BAD 各半，用于判断增加数据是否持续有效。
- 新盲测 Test 全程封存，不用于 checkpoint、阈值、Prompt 或训练参数选择。

## 3. 方向二：专用视觉二分类器

第一候选采用 **SigLIP2 So400m NaFlex + 二分类头**。分类器负责 GOOD/BAD 概率，Qwen3.5 继续负责异常原因生成和低置信度样本复核。

实验顺序：

1. 使用现有约 8,026 张独立原图训练线性探针，只训练分类头。
2. 依次加入 D2K、D4K、D8K，形成数据学习曲线。
3. 线性探针达到可用水平后，只对最佳数据规模解冻视觉编码器顶部若干层。

首轮固定 NaFlex 输入和 `max_num_patches=1024`，不同时扫描分辨率和骨干网络。扩展 Dev 上固定两种工作点：

- 平衡型：FPR≤10% 时尽量提高 Recall；
- 召回型：FPR≤20% 时尽量提高 Recall。

若分类器在相同 FPR 下提高 Recall，或与 Qwen 的逐图错误明显互补，则继续验证“分类器初筛 + Qwen 解释/复核”。若线性探针和部分解冻均明显弱于 Qwen，且 D2K→D8K 没有稳定收益，则停止该路线。

## 4. 方向三：Qwen3.5 受控改造

本方向继续使用表现更可靠的 Qwen3.5-27B。固定 LLM+aligner `all-linear` LoRA、ViT 冻结、rank 16、alpha 32、dropout 0.05、BF16、ZeRO-2 和全局 batch 16；按扩展 Dev 的图片级指标选择 checkpoint。

只进行三个受控实验：

- **Q1 高视觉分辨率**：仅将 `IMAGE_MAX_TOKEN_NUM` 从 1024 提升到 1536，数据和其余参数保持不变。若无明确收益，不继续测试 2048。
- **Q2 decision-only 多任务**：保持分辨率 1024。新增 D8K 使用独立 Prompt，只输出 GOOD/BAD；现有带原因数据继续输出严格 JSON，不为新增图片伪造错误原因。
- **Q3 组合实验**：只有 Q1 和 Q2 都在扩展 Dev 上独立有效时，才组合 D8K decision-only 与 1536 图像 token。

当前不增加 crop、不提高 LoRA rank、不解冻 ViT，也不同时修改学习率、分辨率和数据任务。若三个方向均无法在新盲测上稳定超过 Qwen3.5 对照，再考虑更换其他大型多模态基模。
